## 🚀 À propos du projet

Cette application de gestion de tâches a été conçue pour exploiter la puissance du typage statique avec **TypeScript** combinée à une interface utilisateur moderne. Elle permet de :

- ➕ **Ajouter des tâches** en temps réel avec un typage strict des données.
- 🗑️ **Supprimer et gérer** efficacement les éléments de la liste.
- ⚡ **Filtrer et interagir** grâce à des composants fluides et réactifs.
- 🎨 **Bénéficier d'un design soigné** propulsé par Tailwind CSS et DaisyUI, agrémenté d'icônes vectorielles Lucide.

## ⚙️ Installation et Démarrage Rapide

Assurez-vous d'avoir **Node.js** et **Git** installés sur votre machine, puis copiez et exécutez la commande unique ci-dessous dans votre terminal pour cloner le projet, installer les dépendances et lancer l'application en un clic :

```bash
git clone [https://github.com/tchoupo237/NOM-DU-DEPOT.git](https://github.com/tchoupo237/NOM-DU-DEPOT.git) && cd NOM-DU-DEPOT && npm install && npm run dev
```
